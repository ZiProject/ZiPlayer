ZiPlayer Web Audio

Search for a track through the configured ZiPlayer source plugins, then connect to its live PCM stream.

Enter the listener token below before searching. Search and play automatically connects this page to the new audio stream. You can also use the session fields below to connect manually.

Disconnected

Recording captures the received 48 kHz stereo PCM into WAV while playback continues. Browser memory is capped at 10 minutes per recording; use Download current WAV to save a snapshot without stopping capture.

For browser connections the example gateway accepts a token in the listener URL. Use a short-lived token and serve this page over HTTPS/WSS outside local development.
